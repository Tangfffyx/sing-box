# 7.0.0 阶段 H 验收

首页依次显示核心功能、系统维护和扩展功能。系统维护用 5–6，WARP 和 Telegram Bot 用 7–8。未发现 sing-box 时才提示去「安装与卸载」。系统工具不再提手动校时。

Telegram Bot 首次进入指向 1。单机运行会提示从 BotFather 取 Token，配置后显示实际机器人用户名，并指引管理员点「开始」后选 3 发送测试。第二台从首台「Telegram Bot」页面复制主控地址和接入密钥。绑定链接生成后才提示交给选中的用户。停用时保留配置，再选 1 恢复。

## 验收结果

- 两种内核状态下均验证了首页 1–8 的分派、子菜单返回后的继续选择、0 退出和首次提示。
- Bot 菜单使用临时配置验证了首台配置、通知测试请求、用户绑定链接、第二台接入和保留配置后的恢复。
- Bot 后端测试验证了通知发给配置的管理员，用户只看到自己的绑定，绑定链接只能使用一次，并在到达 10 分钟时失效。
- WARP 首次进入可直接选预设，已配置的网站显示对应去向。
- 全量回归和单文件重新构建一致性通过。

Telegram 消息发送、服务启停和第二台的数据上报使用测试替身。实际手机收信和两台公网服务器接入待联机验收。
