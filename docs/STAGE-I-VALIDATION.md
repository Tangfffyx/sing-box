# 7.0.0 阶段 I 验收

## 发布构建

在施工目录执行 `bash build.sh` 和 `bash tests/check.sh`。全套通过，独立重建的单文件脚本逐字节一致。已验证脚本嵌入的 Python 语法、A–H 的回归和两种卸载分支。候选文件的 SHA-256 为 `8da3525f6b0c91d8a71199a7f1b7b068798da89913a2bc66794e3993f19554bc`。本轮只做本地构建。

CI 定义增加 Debian 的夹具回归和生成脚本的安装回环测试。真实内核测试包含 WireGuard 构建标签。测试分支沿用基线发布工作流。此处记录的是工作流配置，Linux CI 尚未执行。
