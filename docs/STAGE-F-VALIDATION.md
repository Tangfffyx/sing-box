# 7.0.0 阶段 F 验收

首页、用户详情和安装完成页共用导出流程。首页先显示管理员节点，选「导出全部用户」才扩大范围。用户详情按有效权限过滤。安装完成页限定本次成功安装的节点，单节点直接展开，多节点可按一种格式批量导出。

交互页依次提供通用链接、Clash / Mihomo 和 Quantumult X。SOCKS5 的第一项叫「落地链接」。二维码由服务器上的 qrencode 直接编码通用链接。宽屏在二维码右侧显示格式，窄屏上下排列，空间不足或二维码生成失败时显示完整链接。
