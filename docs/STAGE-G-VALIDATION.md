# 7.0.0 阶段 G 验收

WARP 菜单可以直接选网站。规则已有部分流量中转时，先确认是否改走 WARP。规则集会先下载并验证格式，然后通过独立 sing-box 配置强制走候选出口访问 Cloudflare trace。只有收到 `warp=on` 或 `warp=plus` 才提交配置。

优先复用现有 WireProxy 的 SOCKS5，支持自定义端口、IPv6 回环和认证。常见已停止服务需确认后启动。已发现 WireProxy 但出口验证失败时，菜单提示检查并重试。支持 TCP 的 WireProxy 出口使用 TCP 模式，匹配的 UDP 流量没有直连回退。

全新机器先验证内核支持用户态 WireGuard。确认 Cloudflare 条款后使用经固定 SHA-256 校验的 wgcf 2.2.30 注册。账户和配置保存在管理目录的 `warp/` 下，握手失败可以重用。取消最后一条分流会撤下对应出口和路由，保留注册资料，外部 WireProxy 继续由原服务管理。

## 已通过

- 模拟普通 SOCKS 或隧道异常导致出口验证失败、规则下载失败、接管取消，以及配置写入后服务启动失败。生产配置写入流程恢复了原配置和元数据。
- 同一规则重复启用不会重复下载或重启。握手失败后重试不会再次注册。取消最后一条规则后，原有中转继续保留。
- 真实 sing-box 回环转发验证了命中规则的流量到达指定 SOCKS 出口，未命中流量走直连，并验证了全量和部分中转。
- 官方 sing-box 1.14.2 校验了生成的用户态 WireGuard 配置。全量脚本回归和单文件构建一致性检查通过。
